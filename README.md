# Pagini Magice 📚✨

Salut! Acesta este **Pagini Magice**, un proiect creat special pentru iubitorii de cărți. Practic, este un website dedicat unei librării/biblioteci unde cititorii pot descoperi cărți, informații despre literatură, oferte speciale și noutăți.

## 🛠️ Tehnologii folosite
Proiectul este construit folosind tehnologii web moderne de frontend, axându-se pe un design interactiv și responsiv:

- **HTML5:** Pentru o structură semantică, accesibilă și curată a paginilor.
- **CSS3:** Folosit pentru designul general. Am integrat **CSS Grid** și **Flexbox** pentru un layout complex. De asemenea, folosește variabile CSS pentru a menține o schemă de culori armonioasă pe tot site-ul.
- **SASS (Syntactically Awesome Style Sheets):** Folosit în special pentru logica și stilizarea meniului de navigare (`meniu.sass`). Ne ajută să scriem cod CSS modular, folosind variabile, bucle (loop-uri) pentru animații în cascadă.


Proiect realizat cu pasiune pentru web design și lectură. 📖✨
